CSS Box-Sizing Comparison

Both boxes are given the exact same CSS properties: width: 250px, padding: 30px, and a 15px border.

content-box

Actual Width: 340px

(250px width + 60px left/right padding + 30px left/right border)

Padding and border get added to the outside.

border-box

Actual Width: 250px

(Padding and border are absorbed inside the initial 250px limit)

The box stays exactly the size you told it to be.
